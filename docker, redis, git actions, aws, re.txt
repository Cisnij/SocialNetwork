Bạn đang muốn làm giống kiểu link share của Facebook (ví dụ `/share/p/...`) thay vì dùng URL kiểu `/post/3/` đúng không? Mình giải thích và gợi ý cách làm chuẩn cho Django REST nhé.

---

## 🔎 Vấn đề của bạn

Hiện tại bạn đang dùng:

```python
class PostModify(generics.RetrieveUpdateDestroyAPIView)
```

→ View này phục vụ:

* GET (xem chi tiết)
* PUT/PATCH (sửa)
* DELETE (xóa)

Nhưng:

* URL của bạn đang dựa vào `post_id`
* Bạn muốn tạo **link share public kiểu Facebook**, ví dụ:

  ```
  /share/p/<code>/
  ```

---

## 💡 Cách Facebook làm

Link như:

```
https://www.facebook.com/share/p/18PatL9S3R/
```

👉 Thực chất:

* `18PatL9S3R` là **mã encode (không phải ID thật)**
* Nó map tới 1 post trong DB
* View này thường là **public read-only**

---

## ✅ Cách làm đúng trong Django

### 1. Thêm field `share_code` cho Post

```python
import uuid

class Post(models.Model):
    post_id = models.AutoField(primary_key=True)
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    content = models.TextField()

    share_code = models.CharField(max_length=20, unique=True, default=uuid.uuid4)
```

👉 Hoặc bạn có thể custom code ngắn hơn (base62)

---

### 2. Tạo view riêng cho share (QUAN TRỌNG)

Không dùng lại `PostModify`

```python
class PostShareView(generics.RetrieveAPIView):
    serializer_class = PostSerializer
    permission_classes = [AllowAny]  # public

    def get_object(self):
        share_code = self.kwargs.get('code')
        return get_object_or_404(Post, share_code=share_code)
```

---

### 3. URL riêng

```python
urlpatterns = [
    path('share/p/<str:code>/', PostShareView.as_view()),
]
```

---

### 4. Kết quả

Giờ bạn có:

* `/post/3/` → dùng cho owner/admin (modify)
* `/share/p/abc123/` → public giống Facebook

### Bước 2: Định nghĩa Logic bằng `django-rules`
Đây là "trái tim" của hệ thống. Bạn tách rời điều kiện kiểm tra ra khỏi View.

```python
# rules.py (Tạo file này trong app của bạn)
import rules
from friendship.models import Friend

@rules.predicate
def is_post_author(user, post):
    return post.user == user

@rules.predicate
def is_friend(user, post):
    if user.is_anonymous or not post: return False
    return Friend.objects.are_friends(user, post.user)

@rules.predicate
def is_public_post(user, post):
    return post.privacy == 'public'

# RULE: Ai được xem bài? (Tác giả HOẶC Public HOẶC (Bạn bè + post để mode Friends))
can_view_post = is_post_author | is_public_post | (is_friend & rules.predicate(lambda u, p: p.privacy == 'friends'))

# RULE: Ai được sửa/xóa/đổi quyền? (Chỉ tác giả hoặc Staff)
# Sau này thêm Group Admin chỉ cần: is_post_author | is_group_admin | rules.is_staff
can_edit_post = is_post_author | rules.is_staff

rules.add_perm('posts.view_post', can_view_post)
rules.add_perm('posts.change_post', can_edit_post)
```

---

### Bước 3: Tạo Permission Class cho DRF
Để kết nối `django-rules` vào các API View của bạn một cách tự động.

```python
# permissions.py
from rest_framework import permissions

class RulesBasedPermission(permissions.BasePermission):
    def has_object_permission(self, request, view, obj):
        # Nếu là các method xem (GET, HEAD, OPTIONS)
        if request.method in permissions.SAFE_METHODS:
            return request.user.has_perm('posts.view_post', obj)
        # Nếu là các method thay đổi (PUT, PATCH, DELETE)
        return request.user.has_perm('posts.change_post', obj)
```

### Bước 4: Tối ưu QuerySet (Lọc dữ liệu hàng loạt)
`django-rules` kiểm tra từng object, nhưng để trang Newsfeed chạy nhanh, bạn cần lọc ngay ở câu lệnh SQL.

class PostFriend(generics.ListAPIView):
    serializer_class = PostSerializer
    permission_classes = [IsAuthenticated]

    def get_queryset(self):
        user = self.request.user
        friend_ids = Friend.objects.friends(user)

        return Post.objects.filter(
            Q(user=user) | # Bài của chính mình
            Q(user__in=friend_ids, privacy__in=[Post.PUBLIC, Post.FRIENDS]) # Bài bạn bè (Public/Friends)
        ).distinct().order_by("-created_at")

View Trang cá nhân
class PostUser(generics.ListAPIView):
    serializer_class = PostSerializer
    permission_classes = [IsAuthenticated]

    def get_queryset(self):
        target_profile_id = self.kwargs.get("user") # Lấy ID profile từ URL
        target_user = get_object_or_404(User, profile__id=target_profile_id)
        request_user = self.request.user

        # 1. Nếu xem tường nhà mình: Hiện tất cả
        if request_user == target_user:
            return Post.objects.filter(user=target_user)

        # 2. Nếu xem tường người khác:
        is_friend = Friend.objects.are_friends(request_user, target_user)
        
        if is_friend:
            # Nếu là bạn: Xem được Public + Friends
            return Post.objects.filter(user=target_user, privacy__in=[Post.PUBLIC, Post.FRIENDS])
        else:
            # Nếu người lạ: Chỉ xem được bài Public
            return Post.objects.filter(user=target_user, privacy=Post.PUBLIC)

### Bước 5: API Chỉnh sửa quyền (Step-by-step cho User)

```python
# views.py
class PostModify(generics.RetrieveUpdateDestroyAPIView):
    permission_classes = [IsAuthenticated, RulesBasedPermission]
    serializer_class = PostSerializer
    queryset = Post.objects.all()

    def get_object(self):
        obj = get_object_or_404(Post, pk=self.kwargs.get('pk'))
        # Kích hoạt kiểm tra has_object_permission ở Bước 3
        self.check_object_permissions(self.request, obj)
        return obj
```

class DeleteConversation(generics.UpdateAPIView):
    permission_classes = [IsAuthenticated,IsConversationMember]
    serializer_class = ConversationMemberSerializer
    def put(self,request, *args, **kwargs):
        conv_id=request.data.get('conv_id')
        conv=Conversation.objects.get(id=conv_id).first()
        user=request.user
        self.check_object_permissions(request, conv)
        if not conv:
            return Response({'error': 'No conversation'},status=400)
        conv_del= ConversationMember.objects.filter(conversation=conv, user=user).first()
        if not conv_del:
            return Response({'error': 'Not a member'}, status=400)
        conv_del.is_del_conv=True
        conv_del.save()
        return Response({'message': 'Deleted successfully'}, status=200)

class Conversation(models.Model):
    TYPE_CHOICES = (
        ('direct', 'Direct'),
        ('group', 'Group'),
    )

    id = models.BigAutoField(primary_key=True, editable=False)
    type = models.CharField(max_length=10, choices=TYPE_CHOICES)

    name = models.CharField(max_length=255, null=True, blank=True)  # group dùng
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    status = models.CharField(
        max_length=20,
        choices=(('pending', 'Pending'), ('accept', 'Accept')),
        default='pending'
    )

    def __str__(self):
        return f"Conversation {self.id}"

    class Meta:
        indexes = [
            models.Index(fields=['-updated_at']),
            models.Index(fields=['status']),
        ]
class ConversationMember(models.Model):
    ROLE_CHOICES = (
        ('admin', 'Admin'),
        ('moderator', 'Moderator'),
        ('member', 'Member'),
    )

    conversation = models.ForeignKey(
        Conversation,
        on_delete=models.CASCADE,
        related_name='members'
    )

    user = models.ForeignKey(User, on_delete=models.CASCADE)

    role = models.CharField(
        max_length=20,
        choices=ROLE_CHOICES,
        default='member'
    )

    last_read_message = models.ForeignKey(
        "Message",
        null=True,
        blank=True,
        on_delete=models.SET_NULL
    )

    joined_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return f"{self.user.username} in Conversation {self.conversation.id}"

    class Meta:
        unique_together = ('conversation', 'user')
        indexes = [
            models.Index(fields=['user']),
            models.Index(fields=['conversation']),
            models.Index(fields=['conversation', 'role']),  # 🔥 quan trọng
