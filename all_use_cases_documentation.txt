


================================================================================
MODULE A: AUTHENTICATION & ACCOUNT
================================================================================

Chức năng:
  - Đăng ký,
  - Đăng nhập,
  - Đăng xuất
  - Quên mật khẩu
  - Đặt lại mật khẩu
  - Đăng nhập Google (OAuth)
  - Kết nối google
  - Kiểm tra mật khẩu
  - Kiểm tra tài khoản có mật khẩu(dành cho google-login)
  - Xóa tài khoản




--- A.1 USE CASE: ĐĂNG KÝ ---

API: POST /api/auth/registration/
View: CustomeRegisterView

Sequence diagram:
  User -> Frontend: Nhập email, username, password, password2
  Frontend -> Backend: POST /api/auth/registration/ (JSON)
  Backend -> Validation: Kiểm tra email/username chưa tồn tại, password khớp
  Backend -> Database: Tạo User + Profile (is_pending=True nếu cần duyệt)
  Backend -> Email: Gửi email xác thực (nếu cấu hình)
  Backend -> Frontend: 201 Created (token + user data)
  Frontend -> User: Chuyển hướng đến trang chính / thông báo xác thực email

--- A.2 USE CASE: ĐĂNG NHẬP ---

API: POST /api/auth/login/ (dj_rest_auth - JWT)
API: POST /api/auth/web/login/ (cookie http-only)

Sequence diagram (JWT):
  User -> Frontend: Nhập email/username, password
  Frontend -> Backend: POST /api/auth/login/
  Backend -> Authentication: Xác thực credentials
  Backend -> Token: Tạo access_token + refresh_token
  Backend -> Frontend: 200 OK (access, refresh, user data)
  Frontend -> Storage: Lưu token vào localStorage/AsyncStorage

Sequence diagram (Cookie http-only):
  User -> Frontend: Nhập email/username, password
  Frontend -> Backend: POST /api/auth/web/login/
  Backend -> Authentication: Xác thực credentials
  Backend -> Cookie: Set http-only cookie (access_token + refresh_token)
  Backend -> Frontend: 200 OK (Set-Cookie header, user data)
  Frontend -> (Tự động gửi cookie trong các request sau)

--- A.3 USE CASE: ĐĂNG NHẬP GOOGLE ---

API: POST /api/auth/google/login/
View: GoogleLogin

Sequence diagram:
  User -> Frontend: Bấm "Đăng nhập bằng Google"
  Frontend -> Google: Redirect đến Google OAuth consent screen
  User -> Google: Chọn tài khoản, đồng ý
  Google -> Frontend: Redirect về app với authorization code
  Frontend -> Backend: POST /api/auth/google/login/ (code)
  Backend -> Google: Xác thực code, lấy user info
  Backend -> Database: Tìm / Tạo User (nếu chưa tồn tại)
  Backend -> Token: Tạo JWT tokens
  Backend -> Frontend: 200 OK (access, refresh, user data)
  Frontend -> User: Đăng nhập thành công

--- A.4 USE CASE: QUÊN MẬT KHẨU ---

API: POST /api/auth/password/reset/
View: CustomePasswordResetView

Sequence diagram:
  User -> Frontend: Bấm "Quên mật khẩu", nhập email
  Frontend -> Backend: POST /api/auth/password/reset/ (email)
  Backend -> Validation: Kiểm tra email tồn tại
  Backend -> Email: Gửi email chứa link reset password
  Backend -> Frontend: 200 OK (thông báo kiểm tra email)
  User -> Email: Mở link reset -> Frontend form nhập mật khẩu mới
  Frontend -> Backend: POST /api/password/reset/confirm/<uidb64>/<token>/
  Backend -> Validation: Kiểm tra token hợp lệ
  Backend -> Database: Cập nhật password mới
  Backend -> Frontend: 200 OK (thành công)

--- A.5 USE CASE: XÓA TÀI KHOẢN ---

API: POST /api/auth/delete-account/
View: DeleteAccount

Sequence diagram:
  User -> Frontend: Vào Settings -> Bấm "Xóa tài khoản"
  Frontend -> Backend: POST /api/auth/delete-account/ (password)
  Backend -> Validation: Kiểm tra password đúng
  Backend -> Email: Gửi email xác nhận xóa
  Backend -> Frontend: 200 OK (kiểm tra email)
  User -> Email: Bấm link xác nhận
  Frontend -> Backend: POST /api/email/cofirm-delete-account/ (token)
  Backend -> Database: Xóa User (cascade all data)
  Backend -> Frontend: 200 OK (thông báo tài khoản đã xóa)

Danh sách APIs:

      POST /api/password/reset/confirm/<uidb64>/<token>/ [auth_views.PasswordResetConfirmView]

--- C.1 USE CASE: TẠO BÀI VIẾT ---

API: POST /api/user/post/create/
View: PostCreate

Sequence diagram:
  User -> Frontend: Bấm "Tạo bài viết"
  User -> Frontend: Nhập nội dung, chọn ảnh, chọn privacy
  Frontend -> Backend: POST /api/user/post/create/ (multipart/form-data)
  Backend -> Permission: IsAuthenticated
  Backend -> Database: Tạo Post
  Backend -> Database: Nếu có ảnh -> tạo PostPhoto
  Backend -> Frontend: 201 Created
  Frontend -> Feed: Hiển thị bài viết mới

--- C.2 USE CASE: XEM FEED BẠN BÈ ---

API: GET /api/user/post/show/
View: PostFriend

Sequence diagram:
  User -> Frontend: Vào trang chủ (feed)
  Frontend -> Backend: GET /api/user/post/show/?page=1
  Backend -> Permission: IsAuthenticated
  Backend -> Database: Lấy post của bạn bè (đã kết bạn), + post công khai, sắp xếp mới nhất
  Backend -> Database: Prefetch reactions, comments count, photos
  Backend -> Frontend: 200 OK (phân trang)
  Frontend -> User: Hiển thị feed bài viết

--- C.3 USE CASE: XÓA BÀI VIẾT ---

API: DELETE /api/user/post/<int:pk>/
View: PostModify

Sequence diagram:
  User -> Frontend: Bấm "Xóa" bài viết -> Xác nhận
  Frontend -> Backend: DELETE /api/user/post/<pk>/
  Backend -> Permission: Kiểm tra user là chủ bài viết hoặc admin
  Backend -> Database: Xóa Post (cascade comments, photos, reactions)
  Backend -> Frontend: 204 No Content
  Frontend -> User: Xóa khỏi feed

Danh sách APIs:
  POST /api/user/post/create/                 [PostCreate]
  GET|PUT|PATCH|DELETE /api/user/post/<int:pk>/  [PostModify]
  GET  /api/user/post/show/                   [PostFriend] (feed)
  GET  /api/user/post/userpage/<int:user>/    [PostUser]

API: POST /api/posts/<post_id>/react/
View: PostViewSet

Sequence diagram:
  User -> Frontend: Bấm nút cảm xúc (Like/Love/...) trên bài viết
  Frontend -> Backend: POST /api/posts/<post_id>/react/ (reaction_type)
